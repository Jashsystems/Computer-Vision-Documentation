I built this repository to explore and strengthen my understanding of Computer Vision through hands-on projects and experiments using Python, OpenCV, NumPy, and Deep Learning frameworks.

In this repository, I worked on image processing, real-time video analysis, masking, edge detection, color spaces, histograms, contour operations, face detection, face recognition, and CNN-based image classification.

My main focus was not just learning theory, but understanding how Computer Vision pipelines actually work by implementing and experimenting with practical projects from scratch.
